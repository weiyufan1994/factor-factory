## 3. W03 接口规格（首批实际施工）

只用普通 Python 数据对象，不引入服务或身份系统。对象是既有研究 journal 的计算视图，不是第二个正式知识库。

### Context

`stage, objective, conditions, evaluation_protocol`：把同类可比任务分开。首版条件精确匹配，宁可不迁移，不通过不透明相似度强行混合；以后可扩展显式迁移规则。条件应来自研究员已记录的观察范围，而不是用事后收益重新划分 regime。

### Action

`action_id, family, mode, estimated_cost, rationale, evidence_refs`。`mode=exploit|explore` 描述意图，不能自动证明新颖性。调用方从已审方法／提案登记中形成候选集，不把任意字符串交给 shell 或 eval。建议器不执行动作，不放宽正式 review。

### Observation

绑定 `run_id, action_id, context, split, protocol_id, metric, direction, baseline, result, scale, actual_cost, status, evidence_ref`。完整原始失败与不完整记录可保留。只有非最终、同协议、有限数、尺度有效、成功完成的实际比较用于策略统计。单个 `PASS`、caller-success 布尔值、收益故事不能产生经验奖励；代码计算增量，语义／证据真实性仍需既有 reviewer。

同协议增量：`clip(direction * (result - baseline) / scale, -1, 1)`，direction 取数值 `+1/-1`；scale 由比较协议预先固定。它是该指标的归一化增量，不是通用信息增益、因果正确率或交易效用。首次版本仅接受 `development` 数据学习；final／confirmation 记录保留但禁止更新本次政策。

### PolicyCandidate 与选择

- 从已接纳开发记录按 context/family 聚合增量与成本；相同 `run_id` 不重复学习；冲突重复明确报错。
- 同类 exploit 优先比较增量／成本；不混合不同协议。未知分支保留机会。
- 事前配置的探索份额只约束本 episode，可为 0 或 1；不是所有课题强制两条路线。明确探索机会、预算用尽及 `STOP` 理由。
- 无证据时给确定性、可复现的轮询基准；知识缺失不禁止创新。负证据只降低对应条件下的优先级，不永久封禁。
- 结果输出选择依据、引用、预算与局部策略版本；仅建议下一动作。更新不自动生效于其他研究，不改全局 Skill、KB 或 provider 配置。

`select_action` / `learn_policy` 采用纯函数，外部读写留给已存在的 journal 路径；不写任意用户路径。首批演示是带清晰标识的工程输入，不声称真实市场研究。

## 4. W04 响应研究切片

本轮实例服务机制探索，不成为永久模型白名单。原始问题是哪些观测能区分暂时压力、永久信息、共同冲击。以公开可观测、带方向的输入 J 与响应 y 为拟合输入；无符号成交量不冒充有符号压力。

简单基准为单尺度因果核；结构替代为双尺度或永久＋暂时分量。记录观察方程、初始状态、离散化、估计方法、约束和可识别条件。等价 ODE/卷积只算一种结构；解析或独立递推实现检验数值一致性，不用同一 helper 自证。

非 LLM 提出器在声明过的模型／参数域内产生并调整候选；LLM 可提出域外机制，由正常研究审查接入。反馈既能引导局部深化，也能触发竞争结构／额外反例。算法不根据拟合最优自行撰写经济解释。

W04a 必须包含实际 GP/SR 演化：初始化、可追溯父代、变异/交叉、有效域检查、数值评价和保留/拒绝；不以手工扫描几个窗口冒称接入 GP。以本项目的推导对象、时序／类型语义和独立测试定义接口；可直接实现所需的小型演化内核，也可复用符合这些要求且许可清楚的库。gplearn 是可评估的工具而非强制依赖；不等待论文代码、作者回复或外部框架移植。自行实现应说明参考思想与本地取舍，不宣称复现论文实验。无需支持所有算子或所有数学模型才交付第一片。

`variation.py` 区分实现等价、测量/估计变体、新机制/响应结构；引用本轮推导和可变范围。等价优化不按收益选胜者；近似要说明误差/有效域；新机制返回 Step2。允许 GP 提出待解释结构，但不把数据启发改写成事前推导。复杂代码与库外数学模型仍可由研究员直接提出，不必先经过 GP。

变异提出器必须实际消费推导得到的数学对象、允许变换、观察映射、区分性预测和当前缺口；不能只在 IC 搜索提示前加一段经济描述。测量/估计变体也由 Step2 核对：改变记忆长度、相位、符号或目标量不能归入纯实现优化。等价性检查包含定义域、初值、时钟、缺失规则与数值行为；近似保留独立候选身份和当轮推导 delta。

W04b 的研究状态使用已有假设、预测、竞争解释、已做实验和成本。MCTS 仅在同协议内分配预算，不自动把多层证据平均成一个分数；不复制默认过拟合分、无限突破加预算或高频子树全局禁用。采用哪种回传规则须在开发比较中说明，不假定带 UCT 名字就有统计保证。

覆盖机制相同而参数变化、噪声变化、永久冲击、多尺度、共同冲击及观测等价。开发与最终评价分开；oracle 可持隐藏真值，拟合不得读取。因数值不显著返回证据不足；只有结构推导或明确等价证据才称不可识别。

首轮有界用量计划：每个研究 episode 最多 3 次响应结构修订，每轮最多评价 16 个有效候选，另设 32 次无效生成尝试上限；允许提前停止，不要求跑满。算法更新不是每个候选都增加一次 LLM 调用。跨任务比较预定匹配、条件变化、误导性先验三个任务族，各用 3 个数值种子；开发/评价问题分离，C0/C1 同预算、同工具，两者均可当轮修订。真实独立研究验收至少覆盖三个任务族，不提供 oracle 答案给作者。改变这些上限须在查看对应结果前说明，不能事后挑最好种子。

## 5. Ultimate 与 Tutor 接线

Step1 保持原文理解，不改默认流程。Step2 按研究需要调用方法和推导检查，正式冻结前可探索；Step3 实现获选对象，独立 Step2 复审真实代码后才测试与正式执行。Step4/5 的疑似 bug 回传 Step2/3；真失败交 Step6 分层诊断。Step6 把“结果→判断→下一动作”的差异保存在现有 journal/handoff，再形成更新候选。

算法结果仅能作为 Step2/6 的证据输入，不能伪装 agent-authored 正式对象。接线若需要增加字段，做明确局部兼容变更；不删除现有主体验证。普通研究默认不启动 hybrid pilot。

每轮新响应结构完成架构书第 6 节的 math induction，先从新假设做前向推演，观察数学带来什么研究内容，再检查一致性，不把它缩成回测前检查表。将本轮前提、符号／信息时点、关键公开推导、新发现或未推出的含义、观测映射、结论／缺口和相对父结构的差异放在已有 Step2 研究记录及 Step6 journal/handoff；不新建独立数学审批服务。主 Skill 明确“每轮必做”，详细问题按需加载。已有推导可以引用，但不能只复制结论或跳过本轮假设变更。

Tutor 在复杂推导／数学代码复核／失败解释时采用 audit，它的调用按需不改变推演必做。仓库候选可被明确引用，正式安装等 W09。真实独立 review 仍由另一执行主体完成。
