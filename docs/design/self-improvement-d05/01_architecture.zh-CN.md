# D0.5：机制与表达式两层搜索

2026-10-10 · 本地施工版 · 继承 D0.4 的 mechanism-first 主线。

## 1. 要交付什么

让算法帮助研究员**发现、实现和检验数学机制**，而不是替高分公式补经济故事。用户仍以 Ultimate 为研究入口；Step1 理解原文/用户假设，Step2 推演，Step3 实现，Step4/5 检验，Step6 反思并决定下一轮。搜索是这些步骤内部的工具，不是另一条挖因子流水线。

本次同时补齐两个层次：

| 层次 | 搜索对象 | Exploit | Explore | 交付物 |
|---|---|---|---|---|
| L1 研究/机制层 | 经济假设、数学对象、响应结构、观察映射、区分实验 | 深化当前结构、识别参数、检查边界和失败原因 | 提出竞争机制、改变结构或选择更有区分力的观测/实验 | 新的推导、预测、反例、识别缺口及下一研究动作 |
| L2 表达式/实现层 | 在已推导范围内的算子树和估计器 | 参数/子树改进、实现比较、合法交叉 | 实际生成新树、扩展未访问的表达式分支 | 可读公式、标准 Factor 对象、factor values 和检验结果 |

L1 的 MCTS 搜索研究动作与后继研究状态；L2 的 GP/MCTS 真正生成表达式结构。仅将固定 candidate_hash 列表接入 UCT，或在三条预置公式之间轮换，均不构成本版完成。

最小工作流：

```text
经济问题 → L1 提出/选择机制或区分实验
                    ↓
         Step2 本轮前向 math induction
                    ↓ 推导限定可变范围
         L2 生成/变异/交叉/扩展算子树
                    ↓
         标准 Factor → Step3 代码复审 → Step4/5
                    ↓
         Step6 分层解释证据 → L1 下一动作
```

公式越出已推导的响应家族时，返回 L1/Step2；不能先评价收益再决定它“仍属原机制”。

## 3. 每轮响应结构的 math induction

这里的 induction 指从经济前提进行**前向建模和推导**，不限定为数学归纳法，也不强制套用 SDE。研究员记录：

1. 经济前提、竞争解释，以及相对父结构改变了什么。
2. 数学对象、状态/观测、符号、定义域、初值与合法信息时点。
3. 从前提推到性质、响应、可区分预测或反例的关键公开推导。
4. 观察与估计桥梁：保留/丢失的信息、代理、数值近似和适用域。
5. 检验/证伪方法，以及已经推出、尚未推出或矛盾的结论。

一个正确推导可以得到“无法识别”“无法推出收益方向”或“当前假设不成立”，不要求每轮产生 Dirac-style alpha。Dirac-style 的追求是结构清晰、机制强约束，而非为通过流程制造一个信号。

### 变更怎样处理

| 变更 | 数学工作 | 能否直接进入本轮效果评价 |
|---|---|---|
| 实现等价 | 引用原推导，并核对定义域、时钟、初值、缺失语义及独立数值 parity | 通过原有代码复审后可以；不按收益选择“等价”版本 |
| 已推导估计/参数域内变体 | 引用家族推导，说明本点的观察/误差含义与范围检查 | 通过范围检查与原有代码复审后可以 |
| 新经济前提、对象、响应结构或未覆盖的观察映射 | 本轮重新推演相关部分，记录父子差异 | 推导与研究判断完成前不做效果评价 |

“使用了允许的算子”“单位相同”或 `induction_done=true` 都不能证明语义仍在范围内。范围由推导中的响应家族与可变规则限定，而非宽泛 operator allowlist。域外树可以保存为待研究问题，但不调用其 fitness。

实现只核对推导记录与本轮结构/范围的对应、内容存在、评审结果和变更分类；不声称机器验证了经济真实性或数学证明。复用既有 Step2 记录与独立 Step2→Step3 复审，避免另建数学审批系统。Tutor 只在复杂推导、观察桥梁或反例上按需参与。

结果后产生的新结构明确标注 data-inspired；重新推导不抹掉已见数据，也不使同一批数据重新成为独立确认样本。

## 4. L1：研究方向与机制搜索

研究节点是现有研究记录的计算视图：经济问题、假设/竞争假设、数学对象、响应结构、可辨预测、观察范围、当前证据和未知项。节点不是预先列死的模型字典；LLM/研究员可以提出目录之外的新机制和 direct-code 对象。

研究动作至少区分：深化/估计、推导新结构、设计区分实验、检查实现或观测、停止/保留未知。每次扩展形成实际后继研究状态，记录为什么值得做、依赖什么、预算和对应证据。MCTS 分配研究资源，不承担经济解释的作者身份。

树搜索保留未访问分支的机会，同时利用同条件下已经取得的证据。UCT 在此是有界启发式，不对非平稳研究过程声称最优性保证。探索份额与停止条件按课题设定；不强制凑够竞争分支。

L1 不以 IC 大小给经济机制投票。优先采用事前定义的区分实验结果、估计误差/预测误差变化、反例与实际成本；只有相同目标、协议、数据暴露和尺度的结果才能数值比较。纯推导完成度、review PASS 或 LLM 自报“信息增益”不作 reward。没有可比的数值结果时可用明确的待研究次序/人工选择，不伪造一个分数。

估计损失、预测效果和交易净收益分别回答不同问题。零 alpha 或负净收益可能来自没有收益方向、估计器差、成本或不合适的实现；只有针对机制预测的有效反证才能支持否定该机制。L2 的低分不能自动写成 L1 的机制 verdict。

## 5. L2：真实的表达式搜索

类型化表达式树复用现有 Formula IR 的 field/constant/operator 节点和 operator registry。搜索侧增加轻量语义约束，不复制算子数值实现。

类型维度分别记录，不能把不同概念混成一个枚举：

- 形状与值类型：scalar/panel、numeric/boolean（仅实现支持的部分）。
- 单位/量纲、字段含义与数据可用时点。
- 时钟与分组：交易日/分钟、同 instrument 时序或同日截面。
- 窗口、缺失/零值、定义域和预热要求。
- 响应家族、数学目标及推导允许的转换规则。

首版支持小而真实的数值 panel 子集：字段、有限常数、加减乘除、因果 delay/rolling mean，以及实际实现且有明确语义规则的操作。每个算子必须同时被现有 registry 支持和本轮范围允许；尚无类型规则的算子可继续普通 direct code 研究，不伪装为已支持的自动搜索。

生成器从带类型的空位扩展树，支持参数变异、子树替换、同一推导范围内的合法子树交叉、多代选择及停止。公式 MCTS 的动作是填充/替换表达式结构，评估完整树后回传，而不是只排序历史候选 ID。记录随机种子、父代、真实变更、无效尝试、重复、评价调用和成本。

复杂度/深度/候选次数有界。规范化只做已建立语义的表示归一与去重；浮点结合律、带 NaN 的恒等式、剪枝近似不能随意当作精确等价。除零/截断不偷偷改公式；沿用原算子的行为并显式验证。

编译路径为 AST → 现有 Formula parser/IR → `FormulaFactor`（或既有 reviewed direct/hybrid Factor）。输出保持 `datetime, instrument` 唯一有序 MultiIndex + `float64 factor_value`，保留 NaN 与真实零。生成树不需要新回测器、数据服务或每因子 wrapper。

## 6. 两层如何交换证据

一次循环按顺序：选择研究动作 → 完成本轮结构推导 → 实例化合法表达式空间 → 有界生成与评价 → Step6 区分实现/观测/估计/机制问题 → 保留、修订、探索或停止。

L1 接收有条件的实验摘要和原始结果引用；L2 接收具体数学目标、合法变换和检验方法。两层统计分开但共用研究预算。已有候选/试验账本仍负责真正 Step4/5 的保留、执行与恢复；未完成/失败/重复试验不能变成免费成功样本。

开发样本用于搜索；未使用确认样本用于固定方案后的判断；OOS 沿用现有独立边界。多个节点消费同一结果是证据复用，不是多个独立发现。新的推导并不能消除多重搜索偏差。

知识库提供经验和竞争解释，允许研究员拒绝不适用先验。学习改进的对象是条件性的动作选择、语法范围、诊断与研究方法；不是自动改写已安装 Skill 或给高分公式追认经济逻辑。

## 7. 不变的公共接口

`BaseFactor.compute/run/__call__`、`FormulaFactor`、`research_api`、Data API、算子数值语义、Step3/4/5 CLI/工件和 metrics 不改。本版增加搜索模块和薄适配，旧研究关闭搜索时行为保持一致。

用户应能查看：推导和父子差异、带注释公式/代码、head/tail/边界 sample、调用原有回测 API 的代码、标准 metrics、搜索轨迹及 Step6 的公开结论/下一问题。仅交 JSON 状态和测试数不算研究交付。

## 8. 怎样才算完成

先验收真实能力：产生未预列的表达式；真实变异/合法交叉；机制树有实际后继实验；新结构缺推导时不评价；反馈改变后续动作；完整输出经过原标准接口。再独立判断效果：同预算比较简单搜索与 MCTS/GP；跨任务比较冻结经验 C0 与更新经验 C1。准确率、研究结论质量、代价分别报告，无增益也可完成有效测试。

合成测试证明工程与已声明的数值性质，不证明真实 alpha；一轮真实研究证明可用性，不证明普遍 self-improvement。发布、真实研究 pin 切换和新的市场试验在相应阶段明确实施，不在本地代码测试中隐含发生。
