## 3. B1 的最小可执行设计

研究例子使用合成的有方向输入与可观测响应，或明确的无量纲 panel 特征；不读取市场收益。例子本身有前向推导，而不是从测试答案反写机制。

搜索范围从已有 Step2 induction 的响应家族、允许变换、输入/输出量纲、时钟、窗口、缺失规则和数值有效域投影。实现采用小 Python 对象/纯函数；引用现有研究记录，不创造第二套正式研究对象。

AST 采用已有 IR 节点形状。类型检查与 operator registry 的 arity/backend/lookahead 规则同时生效；输出能被现有 parser 和 FormulaFactor 执行。类型兼容只是必要条件，语义归属必须匹配 induction 范围。

例如首片若声明因果齐次线性响应，实际 AST 检查应拒绝 `x*x`、`x/x` 等变量非线性，即使 x 无量纲且输出类型相同；允许的常数缩放、因果平移/均值与线性组合应能组合出非预列结构。换成非线性族须先有对应新推导。首版只支持已实现家族检查规则，不用任意 `response_family` 字符串冒充可验证归属。

公开推导记录必须有真实前提、关键推导、观察桥梁、父子差异和结论，并与本轮范围对应。`induction_complete` 或 review 字符串只能是已有记录/评审的投影，不能单独放行；记录可以是小对象或现有 Step2 引用，不需要新的签名/审批设施。

生成/变异/交叉实际改变树，记录父代与拒绝原因；无合法子树时返回空候选/停止而非造一条 dummy。固定随机种子可复现，但测试要用多个种子和结构性质，不能硬编码期望三条公式就宣称搜索完成。

编译/计算前检查数学范围，效果 evaluator 只接受本轮已适用的 induction；缺少/过期/不同结构记录时 evaluator 调用数为零。编译和纯数值 oracle 检查不冒充正式 Step3 审查或 efficacy evaluation。

## 4. B2/B3 的关键行为

- L1 扩展需要真实 proposal/实验的内容和后继状态，不只是改机制 ID。新内容可以由研究员/LLM提出；首个离线例子清楚标为测试输入，不模拟 LLM 曾进行推导。
- L2 支持 typed hole expansion、完整 AST 评价和回传。分别测试 GP 的多代选择及公式 MCTS 的扩展，避免拿相同队列改名称。
- 机制判断不等于公式分数。下层负分只更新该实现/估计器；上层反证要来自事前声明的预测与区分测试。
- 支持/反驳方向与动作效用分开；有效反证不自动受惩罚。预测内容以新 ID 修订，不能在已有 ID 下覆盖。协议不匹配的证据不改变机制终局；stop 不虚构实验，也不要求评价 callback。
- 真正效果调用继续使用原有预算与票据；未执行、Unknown、失败与结果复用如实保留。
- 新模块返回未实现动作/需新推导时，交回研究员，而不是后台自行选择一个已有高分结构。
- 旧 `registered_queue` 与现有候选 MCTS 不改名；本版两层功能采用显式选择，关闭时旧行为等价。

## 5. 必须通过的验收（行为，不是字数/字段打勾）

| 测试 | 可复核标准 |
|---|---|
| 真生成 | 实际获得未预列 AST；父代→子代结构有差异；有合法交叉和多代 trace；重复/非法尝试计入记录 |
| 类型与时间 | 错量纲相加、错误分组/时钟、未来引用、越窗、NaN/零混淆和不支持算子有明确结果；不静默修公式 |
| 语义不等于类型 | 单位相同但改变响应/符号含义的树不能复用不适用的 induction |
| 每轮推导 | 缺新结构推导/套父引用时不调用 fitness；域内参数可复用并核对；矛盾或无法推出 alpha 是合法研究结论 |
| 独立数值核对 | 人工公式/独立 pandas 或递推 oracle 与生成 Factor 对比，包括边界、预热、NaN 和未来扰动 |
| L1 研究动作 | 至少两条可区分的后继动作确被展开；不同证据改变下一动作；观测等价时不假装已识别 |
| L2 算法 | GP 有真实选择/变异/交叉；MCTS 有树扩展/rollout/回传；固定队列不算通过 |
| 分层反馈 | 正 IC 不能覆盖数学矛盾，负 IC 不能自动否定机制；无可比 reward 不补假分 |
| 稳定接口 | 标准 Factor/schema/metrics 与旧实现一致；公共源码不改；现有 Factor、research API、搜索生命周期及原生 Step3/4/5 回归通过 |
| 完整循环 | 推导→生成→代码复审→原接口4/5→Step6 公开判断→下一分支；不是只成功写日志 |
| 方法价值 | 同工具/预算比较简单搜索和复杂算法，保留全部失败和成本；无收益明确报告，不挑最好种子 |
| 自改进价值 | 独立新任务上比较冻结经验 C0 与更新经验 C1，避免把同题拟合改善或一例成功叫普遍 self-improvement |

前九项在离线工程测试实现；完整循环先做合成，再由独立研究员做真实使用验证。市场测试继续沿用既有研究数据/样本边界和标准接口，不新增数据治理工程。
