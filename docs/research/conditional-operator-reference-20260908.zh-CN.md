# 条件化算子参考：观测对象、边界与反例

这是一份研究前的算子地图，不是因子公式、市场状态分类器、收益结论或投资建议。每个算子只能在已声明的观测对象、信息时点和反例下作为候选测量；它不能推出固定 regime、因果 payer 或可交易收益。

| 组 | 数学对象与输入/时间尺度 | 保留与丢失 | 条件化假说、适用失效与反例 |
| --- | --- | --- | --- |
| `return / log / delta` | 正价格过程的 (r_t=P_t/P_{t-1}-1)、ℓ_t=log P_t-log P_{t-1})，或价格差分 ΔP_t；相邻已对齐 bar、日或预声明多期窗口。 | 对数收益可在连续正价格段相加；差分保留价格单位和方向，损失跨标的尺度可比性。缺 (P_{t-1}) 或时点不齐时保留缺失，不能补成零收益。 | 只有当分母、复权、可得时点和持有期匹配时，变化率才可作为候选反应率。公司行为或 (P\le0) 使该对象失效；同一 ΔP 在 10 与 100 的价格水平并非同一百分比冲击。 |
| 同方向均值与偏离；CS vs TS | 同方向均值 μ、偏离 (x-μ)、横截面 (x_{i,t}-mean_i(x_{i,t}))，或个体时间序列 (x_{i,t}-mean_s(x_{i,s}))。尺度须明确为当日截面或仅截至 t 的历史窗。 | 均值保留一阶位置；偏离保留相对位置但丢失绝对水平。CS 与 TS 参照集合不同，不能互换；缺观测缩小样本须记录。 | 仅当理论关心“同日相对暴露”或“自身历史异常”时对应使用。共同市场位移可让 CS 偏离为零而 TS 偏离显著；反之亦然。 |
| `rank / z / MAD` 与零值 | 序数 rank、均值/标准差 z，或 median/MAD 稳健尺度；每个预声明截面或历史窗口。 | rank 保序但丢失间距；z 保留线性尺度关系；MAD 对异常值稳健。rank 的 ties 必须保持；MAD=0 不等于有限输入恒定，warmup/无基线仍是缺失。 | 只有目标是相对顺序或预声明标准化时适用。`[0,0,0,1,2]` 的 MAD 为零却非恒定；将它全置零破坏排序，不能把实现修复解释成经济结论。 |
| `mean / sum / causal convolution` | 窗口和、均值，或 (z_t=sum_{k=0}^{K}h_kx_{t-k})；固定、仅向后的窗口及权重。 | sum 保留总量且随窗长变化；mean 归一化长度；因果卷积保留有限历史加权，丢失窗外信息。未完整历史应保留 missing 或明确有效样本数，不得隐含未来 padding。 | 只有机制预先给出累积、平均或衰减核时可选。相同均值可来自一次尖峰或持续流；居中核使用 (x_{t+1}) 即为泄漏，不能称在线信号。 |
| `std / skew / kurt` 的方向 | 二阶离散度、三阶偏斜、四阶尾部/峰度；预声明滚动窗并有最小有效数。 | std/kurt 对所有输入同时取负不变，skew 则变号；三者都不自带未来预测方向。高阶矩对极端值和样本量敏感，样本不足仍是缺失。 | 高 kurt 可以由上行跳跃、下行崩跌或脏值产生；正 skew 描述当前样本不对称性，不证明下一期上涨。须有独立机制与时点检验。 |
| `argmax`、量峰与递归 | `argmax(v)` 的峰位，以及对各子窗口重复寻峰的递归分区；不是峰值幅度，也不是独立事件到达间隔。 | argmax 保留预声明 tie 规则下的峰位，丢失峰高、次峰与完整路径；递归使用局部峰位形成分段。缺 bar 或 ties 不得用 ticker 随机打散。 | 仅当峰位与分段是声明对象时适用。两个窗口可有相同 argmax 但次峰差异巨大；峰值归左/右、端点是否参选改变区段收益。量峰也可能是例行成交，不能推出 attention、压力或收益。 |
| winsor 与条件门控 | 截尾 (clip(x,a,b)) 或布尔 gate (1\{c_t\})；阈值、样本和信息时点在观测前冻结。 | winsor 减少尾部影响但扁平化极端幅度；gate 改变进入样本/组合的测量域。未观测条件不得视作通过。 | 仅当数据质量、可执行性或明确机制条件先验存在时适用。若低流动性正是 payer 的代理，门控可删除对象本身；事后选择阈值或 regime 不是验证。 |
| `corr / residualize / neutralize` | 同期/滞后相关，或 (x=Z\beta+e) 的残差；控制集、拟合窗、权重、可得时点和最小样本须固定。 | correlation 描述共变；残差保留相对控制集的未解释部分，丢失共同成分且依赖模型。控制变量缺失时残差应缺失或明确缩样本。 | 仅当控制集对应已声明混杂/风险暴露时适用。加入 mediator 或未来可得控制会改写对象甚至泄漏；零相关并不等于独立或无条件收益。旧 PF 实现若分别对 up/down 计算 rollingStd，而非先合并为 daily 对象，定义的是不同观测量；这是实现差异，不是源算法或经济机制的结论。 |

## 使用边界与来源

这些是标准数学定义、代数性质与显式反例的参考。它们与现有 `METHOD_MECHANISM_CONDITIONED_MEASUREMENT_SEARCH_20260807` 的“先识别观测对象”边界、`METHOD_SPARSE_EVENT_PROJECTION_FAILURE_20260907` 的 MAD/缺失反例，以及 `METHOD_TRANSIENT_SIGNAL_MODELS_20260907` 的因果窗口边界一致。没有读取市场数据、回测结果或收益序列；也没有引入外部市场推荐。

对任一候选实现，先冻结输入、时间尺度、缺失政策、ties、控制集、阈值和反例，再比较测量保真度与合法时点。即使算子通过这些检查，也只得到一个可检验的观测映射，而非固定市场状态、因果识别或盈利声明。
