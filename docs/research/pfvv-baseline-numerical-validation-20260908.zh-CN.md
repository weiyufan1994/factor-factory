# 民生 PF / VV 原文基线：数值实现与验证

日期：2026-09-08。交付的是可运行的原文构造重建，不是完整回测结果。PF、VV、等权组合的正式 Step1–6 尚未完成；旧 EVENT_U 结果不充抵本研究。

## 先保留作者的研究对象

依据 2025-05-08 民生证券《日内动量脉冲与股价过度反应的精细刻画》，重新读取原文，并查看第 4、7 页图文定义。原始私人 PDF、行情不随试用包分发。

| 对象 | 必须保留的构造顺序 | 已明确的数值约定 |
|---|---|---|
| PF | 同分钟同方向平均收益 → 个股偏离 → 横截面正偏门控 → 合成一个日值 → 20 日标准差 | 主口径为 log1p(个股简单收益减同方向简单均值)；同时检验另一种对数差口径的数值敏感性，不按收益择优 |
| VV | 去前 10 分钟 → 成交量序列递归 6 轮切分 → 各区间收益标准差 → 日截面标准化 → 20 日标准差 | 内部峰值归左，峰值并列取最早；两点拆单点；单点收益不强制为零 |
| 组合 | PF、VV 等权 | 在同一有效股票集合分别截面标准化，再等权取负；不得只剩一个分量还称等权组合 |

PF 不能先分别计算涨、跌两个日序列的滚动标准差，再加总冒充原文。VV 的开盘剔除优先采用原文明确的前 10 分钟与 230 分钟示例，不因另一处 240 分钟表述改变主口径。样本标准差使用 ddof=1；完整 20 个交易日才有滚动结果，缺失股票日占据交易日历位置，不能删掉后压缩成“20 个有效观测”。

这些细节中，原文未唯一规定的部分是分析者事前重建假设，不声称得到了作者原始代码。完整约定在 `examples/mszq_intraday_momentum_pulse/pfvv_reconstruction.json`。

## 经济假设与数学联系，不偷换成结论

作者研究的是短时价格行为与过度反应的联系。我们的形式化解释是暂时性偏离模型：对数价格 p=v+b，b 是可能衰减的价格压力或信念偏离。若衰减存在，则未来变动含有 -λ(h)b 的条件项。该模型是对原文思路的分析者重建，不是作者给出的方程，更不是已经估计出的因果关系。

PF/VV 测到的是经多层聚合的离散程度，不直接测到 b。仍必须检验三个缺口：

- 正偏度描述尾部不对称，不等于上涨股票占比高。
- 最终标准差删除了方向和水平信息；“低离散程度 → 更高未来回报”不是数学恒等式。
- 成交量峰值可以来自信息、流动性等多种机制，不能据此识别投资者情绪或特定交易对手。

保留替代解释：永久信息到达、普通波动率/流动性/市值暴露，以及缺失或陈旧价格效应。历史知识只能建议检验，不能先填失败原因，也不能用小波、Kalman 或 EVENT_U 替换原文基线。

## 可以直接运行的实物

代码：`examples/mszq_intraday_momentum_pulse/pfvv_source_baseline_v1.py`。

公开函数包括 `minute_returns`、`pf_daily`、`vv_segments`、`vv_daily`、`daily_cross_section_zscore`、`rolling_components`。前四项测量日内数据，最后一项产出日历对齐的 20 日分量和等权分数。输入必须由调用方提供；没有网络、行情抓取、收益评估或隐藏中性化。

```bash
python3 -m pytest -q tests/test_mszq_pfvv_source_baseline_v1.py
```

26 项数值测试已实际通过。测试包含独立手算 oracle，不仅是让代码与自己比较：同方向均值、偏度门控、日内合成、递归切分、单点收益、时间排序、尺度变化、未来扰动、缺失日历和共同有效截面的等权组合。

在交叉检查中实际修正过 API 输出缺项、两个分量日期子集对齐，以及 VV 错把已剔除前 10 分钟的缺失用于有效性判断。当前 VV 只验证保留域；第 11 分钟收益若因第 10 分钟收盘缺失而本身不可计算，仍应缺失。PF 的非法简单收益（≤-1）也不进入同方向均值和门控。

## 一个真实分钟日的检查结果

仅读取 2016-01-04 原有 SH/SZ 分钟分区，未调用收益标签或回测。最新检查为研究工作区的 `diagnostics/pfvv_real_day_20160104_v2`；完整本地 CSV/JSON 未随无行情试用包分发。

| 检查项 | 实际结果 |
|---|---:|
| 股票数 | 2,515 |
| 每只股票输入行数 | 241 |
| 保留分钟数 | 240（剔除 09:30 额外行） |
| PF 正偏门控分钟数 | 64 |
| 有效 PF / VV 日值 | 2,515 / 2,515 |
| PF / VV 零值数 | 177 / 183 |
| 全天成交量为零，且两者日值都为零的股票数 | 154 |
| PF 主口径计算 / VV 计算 | 约 0.020 / 0.161 秒 |

以上计算时间不含 S3 下载，也不能直接外推全 IS。有限日值不等于可交易信号；154 只全天零量股票须由既有日度交易约束处理，不能把补齐的分钟网格当作真实成交。该检查仅有一天，尚未生成真实 20 日 PF/VV 或组合分数。

两个事先列出的 PF 对数口径在这一天的日值截面相关系数约 0.999983，最大绝对差约 0.001069。这不是预测 IC、不是收益比较，也不能证明两种口径恒等或可以不披露差异。

## 知识库与修复的验证范围

本次源文重建完成后，实际执行了一次方法补充检索，返回条件化算子参考、历史 rank/correlation 与残差波动案例，以及已纠正的 EVENT_U 扩展记录。它是事后方法核对，不冒充盲测或已经证明知识库提升收益。

- 条件化算子参考用于核对聚合顺序、时间轴、缺失和峰值并列处理。
- 历史波动案例仅提示将来的别名暴露检验，不证明 PF/VV 只是波动率。
- 历史 rank 产品不是同一估计器，其公式与 regime 不移植到本基线。
- EVENT_U 是防止研究对象替换的反例；不能把它的失败说成 PF/VV 失败。

独立于代码作者的 agent 只读复核了 PF/VV 的开盘域修复、Step2 默认原文路由缺失检查、Step6 本地终止判断，未发现新的范围内缺陷。Step6 只检查当前研究身份与本地作者声明的一致性，不声称证明了真实独立会话或抗共同篡改能力。此复核不构成整个系统或研究结论的全面批准。
