# Alpha036 Production Acceptance Research Workspace

This workspace preserves the historical Alpha036 production-acceptance research
report and related materials. It is a research archive, not a reusable framework
entrypoint.

Contents:
- `docs/`: human-readable research report and acceptance notes.
- `scripts/`: reserved for any Alpha036-specific helper that should not live in
  repo-root `scripts/`.
- `results/`: reserved for copied proof summaries.

New Alpha101 or report-specific studies should create a separate
`factor_research/<factor_or_report_id>/` workspace.
