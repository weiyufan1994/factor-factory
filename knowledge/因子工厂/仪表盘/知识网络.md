## 流程接入

- Step1 会把 graph context 写入 `research_discipline.factor_knowledge_context`、`learning_and_innovation.factor_knowledge_context` 和顶层 `knowledge_reference_contract`。
- Step2 会把 graph context 写入 `research_contract.factor_knowledge_context` 和 `learning_and_innovation.factor_knowledge_context_imported`。
- Step6 会把 graph context 写入 `retrieval_context.factor_knowledge_context`，并映射为 analogy-only `similar_cases`。
- Graph context 不能替代同因子证据，也不能绕过 promotion/provenance gate。

Step1/2/6 使用这些标签做检索和联想：动量、反转、价值、质量、低波、流动性、微观结构、Barra 风格、WorldQuant operator 风格、国内指增/市场中性/高频微观结构/ML feature、moneyflow alpha、小中盘 alpha、龙头跟随、私募买方常用的 stat-arb / risk premia / flow alpha / execution-aware / crowding / ensemble feature 等。标签不是模板，也不是 gate；真正的研究仍以经济假设、数学对象和证据为准。

## 写回原则

每轮研究结束后，不只写 Markdown，总结也要形成 graph node：

1. 经济机制：谁付钱，谁接收收益，为什么存在边际错误定价；
2. 数学机制：随机对象、状态变量、方程、推导逼出的因子方向；
3. 证据：IS/OOS、universe、cost、核心 metric、失败边界；
4. 关系边：与旧因子的相似、反例、复用、失败模式；
5. 状态：official / candidate / feature_candidate / rejected / anti_pattern / data_blocked。

分类是检索工具，不是研究框。节点可以同时是动量和反转，也可以同时是微观结构、profit payer、first-passage、ML feature。不要为了填满分类而扭曲经济假设。
