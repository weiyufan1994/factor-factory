# Researcher compatibility entry

Use [Ultimate](../factor-forge-ultimate/SKILL.md) for current research and
[research continuity](../factor-forge-ultimate/references/research-journal.md)
when maintaining the existing journal. Source understanding precedes
supplementary retrieval; a changed mechanism returns to Step2.

This role is merged into Ultimate in the default distribution. Historical
producer strings, journals and the dossier CLI remain compatible. Existing
pinned studies retain their version. No separate role Skill, Host identity or
generic OOS step is needed for ordinary IS.

Independent review needs a distinct context. Author-only sequential role
analysis remains author analysis.
