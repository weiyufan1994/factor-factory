# Factor Forge Step1

Step1 establishes what is being researched. Use the actual source/hypothesis
and the workspace selected by Ultimate. It produces the source interpretation,
chief-adjudicated `alpha_idea_master` and handoff to Step2.

## Understand before supplementing

For `report_replication`, recover components, sign, windows, aggregation order,
normalization and assembly weights. Preserve the author's economic and
psychological logic, labeling source statements versus inference. Mathematical
critique may reveal a gap; it does not replace the source estimator.

A `source_extension` is separately identified. For `independent_hypothesis`,
start from the user's actual argument without inventing a paper. Save a short
source-only understanding before opening prior cases or method suggestions.
Disclose prior knowledge/results exposure; corrective reconstruction is not a
fresh blind trial.

Use real primary and challenger readings in distinct contexts, then source-based
chief adjudication. Preserve original disagreements and assumptions. Similar
answers, JSON validation or a numerical consistency score do not prove fidelity.

## Prepare the mathematical question

Identify the economic mechanism, plausible return source and counterparties,
what must be true and what would refute it. Distinguish evidence from a tentative
payer hypothesis. Describe the mathematical object, target statistic, legal
information time and observation map the source construction attempts to measure.

Choose suitable mathematical tools from the hypothesis. Compare material rivals
and a real null/alias, with distinguishing predictions. The core model and its
map to payoff/price/return are separate. Tools absent from the catalog are valid;
a generic stochastic model or a copied successful formula is not an explanation.

Preserve this authored content in `research_discipline`, including the current
measurement program and knowledge provenance. Use the versioned
[content rules](../factor-forge-ultimate/references/compatibility-constraints.md):
a simple sufficient derivation need not be padded into more models or steps.

## Read for landing

- [Local PDF intake](references/local-intake.md) defines the actual envelopes
  and command; [schema](references/schema.md) defines the source/chief fields.
- When landing the measurement program, read its
  [maintained field contract](../../docs/contracts/mechanism_conditioned_measurement_program_v1.zh-CN.md).
- For state/conjecture/approach records, use
  [Ultimate's research protocol](../factor-forge-ultimate/references/research-protocol.md).
- For actual prior-knowledge consultation, use
  [knowledge maintenance](../factor-forge-ultimate/references/knowledge-maintenance.md);
  the phase-isolated adapter additionally uses the [advisory route](../factor-forge-ultimate/references/epistemic-advisory-operating-delta-v1.md).
- [Question prompts](references/prompts.md) are optional aids, not another
  compulsory checklist. Hosted intake uses Ultimate's explicit hosted route.

Knowledge is a prior, counterexample or tool suggestion. Keep checked indexes,
queries, hits and cold-start reasons; no match is different from a failed query.
The landing CLI preserves supplied research; it does not read the paper,
author a chief decision or certify independent understanding.

Deliver the source construction, unresolved material ambiguities, public
derivation seed and exact artifact paths. Continue through Ultimate to Step2.
A materially underspecified hypothesis stays explicitly incomplete; a new
detector remains a proposal until separately selected.
