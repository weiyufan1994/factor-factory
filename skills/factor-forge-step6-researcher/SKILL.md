# Independent-review compatibility entry

Use [Step6](../factor-forge-step6/SKILL.md) and its
[independent-review guide](../factor-forge-step6/references/independent-review.md).
The guide defines actual separate-context review and the current memo path.

This role is merged into Step6 in the default distribution. The packet-builder
CLI and historical producer identities remain compatible; existing pinned
studies retain their version. Ordinary IS resumes through Ultimate with
`--local-is-only`, not Host environment variables.
