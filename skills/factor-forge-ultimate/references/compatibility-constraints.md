## Local authored-state boundary

The ordinary local profile preserves authored values without rewriting prose.
Missing fields, invalid types, explicit empty values, and populated values stay
distinct through Step6. Explicit empty learning or search declarations require
their authored absence reason; missing and invalid declarations remain blocking.
An OOS metric named as a local search target is rejected by validation, while a
negative warning that says OOS evidence is unavailable remains intact.

For a new ordinary local study, Ultimate or the researcher selects this profile
before the first artifact is landed and carries the same marker through the
actual Step1–Step6 objects; the user does not configure it by hand. Resuming an
older study never adds the marker after results exist and never changes that
study's profile automatically. Older records keep their original interpretation
and remain subject to the validators that applied to their declared objects.
