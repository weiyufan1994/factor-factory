# Research content rules

Read when landing a new ordinary IS study or resuming a study with a pinned profile.
These are supported representations, not a quality score or a substitute for
economic reasoning and independent review.

## New ordinary IS studies

Select `factorforge_ordinary_local_is_flexible_v2` before the first research
artifact is landed. The researcher carries it consistently in the authored
Step1 discipline, Step2 research contract, measurement program and downstream
records; the user need not configure this manually. A marked object still needs
the explicit `local_is_only` execution scope.

Use the shortest sufficient argument:

- A suitable method, its assumptions, one complete derivation and a real null
  challenge can be sufficient. Consider material alternatives, not a fixed number.
- A proposed revision needs an observable prediction, a discriminating test and
  a stopping condition. One of each can suffice; the reviewer judges adequacy.
- A justified stop can have no revision laws or hypotheses. In the proposal
  format, use `no_action` or `reject_advisory`, explicit empty collections and
  `derivation_record.revision_absence_reason`. In the agent result format, use
  the existing advisory no-revision fields; substantive derivation remains required.
- Empty learning/search results carry an authored absence reason. A missing
  field, invalid type or failed retrieval is not an observed empty result.
- Valid IC or event evidence survives an incomplete account evaluation, with
  that limitation explicit. It does not make the account complete or establish
  an adoptable strategy.

An independent task/result uses the same profile as the current study. A
changed or missing selection is rejected; V2 cannot be added to a result alone.
V2 does not change producer identities, approvals, information time, null
challenge, code review, empirical validity or independence requirements.

In the V2 main-agent memo, `expected_metric_signature` holds the predictions
relevant to this hypothesis and matches the mathematical hypothesis's signature.
Supply authored `falsification_tests` and `kill_criteria` explicitly. Projection
to Step6 preserves those lists exactly; observed failures are evidence, not
substitutes for prospective stopping rules. Missing or empty items fail
validation rather than being padded with generic sentences.

## Existing studies and specialized modes

| Selection | Consumer behavior |
|---|---|
| Unmarked/hosted | Existing fixed requirements continue. No new local relaxation. |
| `factorforge_ordinary_local_is_flexible_v1` | Existing local Step1–3 concise modeling and explicit-empty learning/search behavior; Step6 revision evidence keeps its old two-item minimum. |
| Ordinary local V2 | Retains V1 and aligns Step6 proposal, agent result, approval and final validation with the one-substantive-item representation above. |
| Formal EVO | Its frozen qualification/derivation rules continue unchanged. |
| Multibranch synthesis | Its separate executable branch contract still uses one exploit and at most two explorations; an advisory queue or legitimate stop is not that contract. |

Resume with the study's original version. Do not add a marker after observing
results or silently reinterpret historical output. A deliberate migration needs
a new declared study revision and revalidation of the affected stages.

Implementation is centralized in `factor_factory/research_profiles.py`;
measurement/conjecture validators, Step1/2/3 consumers and Step6/Council consumers
use that selection. The old public V1 constant remains V1.

## What validation can establish

Mechanical checks establish structure, object identity, field consistency,
timing and reproducible calculations. A passing artifact does not prove a
payer, a mathematical mechanism, an independent session or economic validity.
State concrete unknowns instead of filling substantive fields with generic
sentinels or borrowed conclusions.

An ordinary local stop retains `formal_proof_eligible=false`, no official
promotion and no OOS claim. Current state/conjecture/approach records still
support its research history; formal certification is a separate mode.
